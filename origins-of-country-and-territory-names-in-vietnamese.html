Origins of Country and Territory Names in Vietnamese

Nov 09, 2026

Venezuela is "Venezuela" in Vietnamese, but the United States is "Mỹ".

Welcome to yet another niche article that no one asks for but I find interesting. Today's topic is about the origins of country and territory names in Vietnamese. I wanted to write this a year ago, but, of course, I'm lazy.

It came up pretty randomly when I was a high schooler. I had some Venezuelans asked me how to pronounce their country name (Venezuela) in my native language, and the answer I got surprised them. They did not believe that a lot of countries in Vietnamese use the same name as in English or in their native language.

Enough yapping for now, let's begin.

Legends:

■ Vietnam
■ Using French name
■ Using Sino-Vietnamese name
■ Using Vietnamese words or fully translated to Vietnamese
■ Using Russian name
■ Using English name
■ Using name that is not used in either English or the country's native language
■ Using name that is similar in the country's official languages
