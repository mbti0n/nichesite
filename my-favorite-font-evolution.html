My Favorite Font Evolution

Oct 23, 2026

A random evolution of my favorite font. And no, Comic Sans is not in the list.

Tahoma

Non-monospace font

I don't remember why I loved Tahoma as a kid. I mean, compared to Segoe UI, Tahoma looks so strong and bold. And it was boring to only use Segoe UI as the system font on Windows 7. It was also during the era of messing up with system settings on Windows 7. What an era to remember.

San Francisco

Non-monospace font

Font for the "rich" during middle school around 2015. 1 out of 10 kids had a smartphone, and the rest were even banned from having a phone — they had to use a dumbphone instead. I was obviously the dumbphone kid, and when I saw stories of my classmates on Instagram (and, especially my crush), I never stopped dreaming of the day I actually had a smartphone and posted like them. Oh, and that was when I loved to use the San Francisco font. The experience was not that good because this font doesn't fully support a low-resolution monitor like my old Dell laptop. But, as a kid who used to spend 4 hours looking for customization stuff, this was a fun experience.

Inter

Non-monospace font

I was amazed when I found out about Inter. How come this font looks so close to Apple's San Francisco? And it's free too?! I used it right away, not just on documents, but also as a system font. Inter is the system font on some of my Linux machines, despite the DE I am using being i3.

IBM Plex Sans

Non-monospace font

At one point I found Inter pretty boring to use, so I tried to find another one to use as my main font. After a quick browse on Google Fonts, I found IBM Plex Sans. And I instantly loved it. It's a good font with large language support, and I find that a mature font, not just because it comes from IBM but also because it’s very clean. The font looks a bit too old compared to Inter, but it is still so hard to call that an ugly font. It looks so clean as both the web fonts and the document font, and its accessibility is very reasonable. I even use that on some of my systems like Fedora Linux or Windows. It's not fully supported, both of them, but it does its job and I loved the experience with IBM Plex Sans.

Overpass

Non-monospace font

I've been driving a lot, and I really love the typography on a lot of road signs. One of them is called Highway Gothic, but it is not a free font.

I was looking for a different font to use on Canvas through an extension called Better Canvas. I found Overpass, and it looks similar to Highway Gothic, although it is more condensed. This font has good language support, although most of the content on Canvas is in English because it's a school-related website. I used this font to design some fake road signs on Roblox Studio. It was a fun experience but not the best one to use around. I find that a bit outdated, compared to other modern fonts like Inter.

Space Grotesk

Non-monospace font

I downloaded inkOS, a minimal launcher optimized for e-ink phones. It has a settings page to change the typography; I selected Space Grotesk. I found that techie yet minimal enough to fit the setup on inkOS. And I loved it. I also got a rooted phone and I wanted to use Space Grotesk as its system font. I found a module on Magisk that changes the system font to Space Grotesk, and it looks pretty cool. The text looks big but still minimal, and it has a surprisingly good language support.

Geist

Non-monospace font

I was looking for a similar font to Space Grotesk, and Geist was mentioned. Looking for this font on Google Fonts, I found that it's so similar to Helvetica. And, it doesn't disappoint me. It is my currently favorite font now, but sadly, it doesn't have rich language support. It struggles rendering Greek scripts, for instance.

Consolas

Monospace font

I'm a Windows user, and Consolas is the default terminal font starting from Windows 10. And, honestly, I think it looks fairly clean, compared to the old console font (Lucide Console), which looks too overwhelming in my opinion.

Roboto Mono

Monospace font

I love Material Design and I love every component of it, including the fonts. Roboto is the main font of it, and its monospace variant also looks incredible. It was in an era that I was writing a lot on my LG tablet (silly delusional me). And, honestly, even now, it still looks incredible.

IBM Plex Mono

Monospace font

I was obsessed with IBM Plex Sans, but I did not know about its monospace variant right away. I eventually found it, and I also loved it. IBM Plex Mono preserves most aspects of the original IBM Plex Sans font, but adds more monospace features like the slashed 0 and monospace width. Its ligature support is good.

JetBrains Mono

Monospace font

This is the go-to font for coders, and, honestly, at first, I did not like this font, compared to IBM Plex Mono. But, after using it, specifically with the Nerd Font variant, I finally understood why everyone uses JetBrain Mono. It supports basically everything, from strong language support to ligatures. And it looks simply cute, combining with a pastel-inspired color scheme like Catppuccin.

Geist Mono

Monospace font

Geist Mono is my current terminal font, following the switch to Geist. However, it is not the best terminal font out here, as it doesn't support ligature text as well as it has poor language support like the original variant.
